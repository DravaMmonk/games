### 第 1 章 · 真值电路（语义）　已做

**模块：** 真值电路用逻辑门算出一句话在一行上的真值，机器把同一块电路在真值表的每一行各跑一遍。原始元件是「非」和「与」。玩家在造门任务中通过的作品封装成新门，可以在后续电路中使用，也可以打开查看内部接线。

| 关卡 | 教学任务 |
|---|---|
| 1-1 至 1-3 | 用两个「非」计算「不是不下雨」，用「与」连接两个命题，再调换「非」和「与」的接线顺序，观察否定范围如何改变真值。 |
| 1-4 造一个或门 | 按简报把「既没下雨，地面也不湿」整体取反，通过后发布「或」门。接着用一个门计算「现在下着雨，或者刮着风」，观察两边都真时的输出。 |
| 1-5 造一个若则门 | 按简报接出「没下雨，或者地面湿」，通过后发布「若…则…」门。接着用一个门计算反向条件句，对照两题的假值行，观察输入顺序的影响。 |
| 1-6 造一个永真门 | 把两个方向的「若…则…」用「或」合并。运行后观察全真的输出列，通过后发布「永真」门。 |
| 1-7 造一个等价门 | 把同样的两个方向改用「与」合并。运行后看同真或同假的两行，通过后发布「等价」门。 |
| 1-8 雨情记录对得上吗？ | 先从一句日常描述找出两个同时成立的命题，再用卡片翻译原 1-6 第二题改写成的雨情记录，最后按公式的层次搭电路，从全假的输出列认识矛盾式。完成三段后解锁 2-1。 |

1-6 和 1-7 隐藏目标列，玩家从运行结果观察两种组合的区别。1-8 第三段的任务板展示玩家最近一次通过「译雨情记录」所提交的公式，接线时可以直接对照。目标列和参考公式仍为隐藏。

**专题：骑士与无赖**（MoC 01）。1-9 起进入选修路线。开篇先交代骑士永远说真话、无赖永远说假话，再用 1-7 造出的「等价」门判断一条证词与说话者身份是否相符。后续谜题继续用公式约束身份组合。专题电路隐藏目标列和参考公式。

| 关 | 加回的机制 |
|---|---|
| 1-9 第一句证词 | a 说 b 是骑士。先把「a 是骑士」与证词内容接成等价公式，再对照任务板上的玩家译文搭电路，判断哪些行符合岛上的规则。四行里有两行符合，只靠这一句还不能确定身份。 |
| 1-10 一个人说话 | 新译法：「a 是无赖」= 非（a 是骑士） |
| 1-11 两个人说话 | 新译法：几个人的话都对得上 = 各句的翻译用「与」接起来；「我们俩都是骑士」= a 与 b |
| 1-12 三个人说话 | 把每个人的「是骑士」分别取反，再用「与」表达「都是无赖」；八行；人数每多一个，行数翻一倍（为归结一章埋下动机） |
| 1-13 至少与最多（终极） | 计数的话改写成「或」：「至少一个无赖」= 三人各自不是骑士的「或」；「最多一个无赖」= 每两人里至少一个骑士，三个「或」用「与」连起来；「a 不是唯一的骑士」= ¬a ∨ b ∨ c。唯一解是 a 骑士、b c 无赖（c 的话恰好为假）；点题联到排班这类问题交给 SAT 求解器时的写法 |

**挑战：** 只有一样（「要么下雨要么刮风，但不会两样都有」，最多 4 个门；逐行拼成要 5 个）。

**不单独做的：** 语法树板（「非」管到哪里已经讲清语法树决定意思）；求值器元件（反模型面板用引擎自己的求值）。

**规格：** 1-8 先练习把自然语言分解成基本命题和连接词，再按公式搭电路。真值表逐行检验可能的情况。1-9 把同一个方法用于身份谜题，检验哪些情况与岛民的证词相符。
