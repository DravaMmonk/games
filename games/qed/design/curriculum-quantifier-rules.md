任取放在最前：声明「存在」要在规则板上任取一样东西，消去规则生成器也要处理带约束变量的引入规则，两处都以它为前提；取一个和存在互不依赖。两条量词线之后，换序与挪动、相等是两条互不依赖的路。「对所有」不声明：任取框和选定一例是证明核自带的（依赖函数类型），「存在」和相等要声明。

**可选专题 · 生成器遇上任取**（`gen-ex`，挂在声明「存在」和每一条之后）：消去规则生成器的第二次升级，板上就是玩家此刻的生成器（每一条那块电路）。引入规则含有约束变量时（⋀x. ⟦?P(x)⟧ ⟹ ∃y. ?P(y)），在生成器中表示为约束了 x 的一条规则，「替换结论」不能直接接受它；新元件 **保留⋀**（框）：若规则以约束变量开头，框内处理其后的规则，输出时在结果前保留原有的约束变量；若不含约束变量，框内直接处理输入。测试是见过的声明加上「存在」，隐藏测试是一条引入规则约束两个变量的声明（框一并保留）。通过后元件指向这一关。关后点明：引入规则约束了哪些变量，对应的情况也约束同样的变量；消去「存在」时无从知道构造时用的是哪一个对象，因此该情况须对任意对象成立，这正是实例框要为该对象引入新名字的原因。专题「卡罗尔的推理题」挂在量词挪出来之后。

**可选专题 · 不声明的连接词**（X8–X9，接在 6-2 取一个之后，还要先做过第 2 章专题里的 K）：不声明，只用 → 和一个管句子的 ∀ 定义（这是 Isabelle/HOL 的 `and_def`、`or_def`；X8 关后点明 Isabelle/HOL 走定义这条路，对应声明「并且」关后点明 Lean 走声明这条路，「并且」「或者」「存在」「相等」都是 `inductive`，只有 → 是核自带的）：A ∧ B 就是 ∀R. (A → (B → R)) → R，A ∨ B 就是 ∀R. (A → R) → ((B → R) → R)，R 是真正的「任何一句话」。不另造元件，沿用任取框和选定一例：关卡里有管句子的 ∀ 时，任取框可取的名字多一个大写的 R（框里的 R 是任意一句话，R 不能出现在未解除的假设里，框外得 ∀R. …），选定一例可选的除了东西还有句子，把 R 换成它（`choices.js` 的 `instance`）。这对应 Lean 的 `∀ (R : Prop)`、HOL 的 `∀R::bool`：命题也是一种东西，对句子量化和对东西量化是同一个 ∀。公式里大写字母的 ∀R 就是管句子的（`formula.js` 的 `prop`），测试的例子不替换它，真值表把它读成「R 为真、为假都成立」。「定义「并且」」两个任务（造：任取框取 R，框里假设 A → (B → R)，套用两次；拆：选定一例把 R 换成 A，再用 K），「定义「或者」」两个任务（造；用：R 换成结论 C，两次套用）。关后点明非直谓：R 连正在定义的那句话本身也能取，这种定义才写得出来。对照：声明写引入规则，消去规则由它生成；定义写消去规则，造和用都由它证出，得到的规则一样。

**可选专题 · 不声明的相等**（X10–X12，接在 6-10 声明相等之后，还要先做过 X8）：a = b 定义成 ∀P. P(a) → P(b)（莱布尼茨相等：a 有的性质 b 都有），三关各证一条规则。∀ 管的是性质，P(x) 是一句说 x 的话：任取框照样取大写的 P；选定一例可选的多了性质（`choices.js` 的 `propertiesOf`：句子的某一部分，把它唯一的自由变量、或其中某一样东西换成 x），每个 P(t) 换成这句话、x 处填 t（`formula.js` 的 `substSentence`）；反例搜索把这种 P 读成「每个子集都成立」。自反（任取框取 P，框里一个假设框，假设就是结论）；代换（性质选 B(x)，套用：就是等量代换，定义直接写下消去规则）；对称（任取框取 Q，性质选 Q(x) → Q(晨星)，再用一个自反的假设框套用）。关后对照：声明给自反律、生成等量代换；定义写下代换，自反和对称证出来。

**名字和变量分开：** x、y、z 只给量词管着用；特指的一样东西（任取框取的、实例框拿出的、选定一例和概括填的）叫 a、b、c（`choices.js` 的 `NAMES`），卡片只提供这些名字。任取框内证出 P(a)，框外给出 ∀x. P(x)：变量取 x、y、z 里第一个没被用到的，和目标比较时不管约束变量叫什么。

**概括自己认例子：** 概括卡片没有「项」这个设置，例子由「要得出」的句子和接进来的句子对位读出；「要得出」默认是「自动」：关卡的 ∃ 句子里只有一句对得上时直接得出它，不止一句时（a喜欢a 既能得出 ∃x. x喜欢x，也能得出 ∃x. a喜欢x）才要玩家选。让卡片按输出接到的目标反推「要得出」，留给第 7 章「逆用规则」当动机。

**规格：** 声明「存在」「相等」是翻译。名字和变量分开、借来的名字不能带走，是规格里约束变量的规矩。
