# Anatomy kit

These MIT-licensed build dependencies come from the local installation of
[wheresryan22/anatomy](https://github.com/wheresryan22/anatomy), copied from its
`kit/` directory. Boxy and Detach use the geometry and audit modules. Boxy
also uses the turning renderer and its build and audit tools. See [LICENSE](LICENSE).
The vendored turning renderer omits two unused helpers.
